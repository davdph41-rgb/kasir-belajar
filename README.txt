# Kasir Belajar

Project latihan POS/kasir sederhana.

## Struktur
- index.html = struktur halaman
- style.css = tampilan
- script.js = logika kasir

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser.
3. Klik `Tambah` pada produk.
4. Masukkan uang pembayaran.
5. Klik `Bayar`.

## Yang dipelajari
HTML → tampilan dan struktur.
CSS → desain.
JavaScript → produk, keranjang, total, pembayaran, dan kembalian.

## Penting
Ini hanya simulasi. Belum terhubung ke database, backend, atau Midtrans.

Tahap berikutnya bisa:
GitHub → Vercel → Backend → Midtrans Sandbox → pembayaran sungguhan.
